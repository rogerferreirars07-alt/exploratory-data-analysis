📊 Exploratory Data Analysis, Data Visualization & SQL Analytics Portfolio

This repository contains data analysis, visualization and SQL analytics projects developed using Python and Databricks SQL.
The objective is to demonstrate practical, end-to-end analytical skills, including data ingestion, data cleaning, exploratory analysis, business-oriented SQL querying, visualization and data storytelling using real-world datasets.

This analysis simulates a business scenario where a retail company needs to understand sales performance, customer profile and revenue drivers to support strategic decisions

Developed as portfolio projects simulating real-world business scenarios and industry analytics workflows.

🔹 E-commerce Sales Analysis — SQL & Databricks

A complete SQL analytics project developed using Databricks SQL, focusing on business-oriented analysis of e-commerce sales data.

Project Objectives

Perform structured SQL analysis using a real-world sales dataset

Build a clean analytical data model (RAW → CLEAN layers)

Answer key business questions related to revenue, product performance and customer profile

Demonstrate SQL best practices, including readable queries and logical organization

Key Analyses Performed

Total revenue calculation

Revenue by product category

Average ticket value

B2B vs B2C sales comparison

Monthly sales trend analysis

Dataset

Amazon sales transactional dataset containing information about:

Orders, dates and quantities

Product categories and SKUs

Sales amounts and currency

B2B and B2C transactions

Project Structure

📁 SQL scripts organized by analytical layer:

01_create_raw_table.sql — Raw data ingestion from Databricks Volumes

02_create_clean_table.sql — Data cleaning and preparation for analysis

03_business_analysis.sql — Business-focused analytical queries

📁 Platform: Databricks SQL
📁 Language: SQL
